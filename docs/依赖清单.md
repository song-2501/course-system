## 三、依赖规模统计

| 统计项 | 数量 |
| --- | --- |
| 直接依赖 | 4 |
| 传递依赖 | 142 |
| 依赖总数 | 146 |
| 其中仅开发期使用（dev） | 123 |

传递依赖均由上述 4 个直接依赖自动引入（主要为 Vite 构建链的 Babel、Rollup、esbuild 系列与 Vue 编译器系列），无需手动维护。完整明细以 `package-lock.json` 为准，该文件已纳入版本管理，可保证在任何机器上安装出完全一致的依赖树。

## 四、依赖安装与验证

```bash
# 安装依赖（依据 package-lock.json 精确还原依赖树）
npm install

# 验证安装结果：查看关键包的实际版本
npm ls vue vite @vitejs/plugin-vue vite-plugin-vue-devtools

# 启动开发服务器验证依赖可用
npm run dev
```

实测记录：`node_modules` 中各直接依赖版本与 `package-lock.json` 声明一致（vue 3.5.42、vite 8.3.0、@vitejs/plugin-vue 6.0.8、vite-plugin-vue-devtools 8.2.1）；`npm install` 后 `npm run dev` 可正常启动，首页与入口模块请求均返回 HTTP 200。

## 五、说明

- `node_modules/` 与 `dist/` 已通过 `.gitignore` 排除，不纳入版本管理；依赖树由 `package-lock.json` 完整锁定。
- 本项目为纯前端单页应用，无后端运行时依赖，无数据库驱动，无第三方 UI 组件库。
- 换机复现时只需 `npm install`，锁文件会保证依赖版本与本机完全一致。
